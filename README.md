### 📱 Projetos Android

- **[Cozinha Timer](https://github.com/94nirvana/app_cozinha)** — aplicativo Android nativo em Kotlin e Jetpack Compose. Organiza a interface, ViewModel, domínio/casos de uso e dados em um único módulo. Usa Room para persistência local e `AlarmManager` para os timers; funciona sem rede.
- **[GymTrack](https://github.com/94nirvana/gym-app)** — aplicativo Android nativo em Kotlin para registrar treinos, séries, cargas e histórico. Funciona offline e permite exportar e restaurar backups JSON. O README do projeto descreve persistência local, sem especificar a tecnologia de armazenamento.

### 🌐 Projetos web

- **[Clima Brasil](https://github.com/94nirvana/clima-brasil)** — interface em HTML, CSS e JavaScript, com servidor Node.js e arquitetura em camadas (`presentation → application → domain ← infrastructure`). Consulta a Open-Meteo e usa cache temporário em memória; não utiliza banco de dados.
- **[todo-terminal](https://github.com/94nirvana/todo-terminal)** — aplicação full-stack em HTML, CSS, JavaScript e Node.js, usando módulos nativos do Node. Organizada por responsabilidades, persiste tarefas em arquivos JSON com escrita atômica e documenta a API com OpenAPI; não usa dependências de runtime.
- **[Crypto Dashboard](https://github.com/94nirvana/crypto-dashboard)** — interface estática em HTML, CSS e JavaScript servida por Node.js, com dados da CoinGecko e cache temporário em memória. Não utiliza dependências de runtime nem banco de dados.

### 🧪 Práticas e ferramentas

Os projetos Android usam Gradle; os READMEs dos projetos web descrevem testes com o runner nativo do Node.js (`node:test`). Os projetos também documentam práticas de validação, resiliência e segurança adequadas aos seus contextos.
